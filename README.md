# 公共座椅管护系统（公园 · 街道）

把公园与街道的公共座椅登记上图，记录**编号、材质、位置、扶手与固定件状态**；
市民报损 → 养护班组接单维修 → 巡查员复验 → 恢复可使用标记。

纯 Python 标准库 + SQLite，零第三方依赖；前端为原生 JS 单页应用（自绘 SVG 地图），
照片本地存储，定位服务使用可替换的**模拟适配器**。

## 一条命令启动

```bash
python3 run.py          # 初始化演示数据（含重复报损案例）并启动
# 打开 http://127.0.0.1:8000

python3 run.py reset    # 清空后重新生成演示数据
python3 run.py --port 9000
```

## 业务规则

- **报损归并**：同一座椅存在未结事件时，新报损自动并入，不重复派单；不同座椅、已结事件
  的归并请求一律拒绝（调度员显式归并接口同样校验）。
- **现场措施**（五类损坏各有处置单）：松动螺栓 → 围蔽停用、紧固/更换膨胀螺栓；
  木板断裂 → 清除断裂木条、换防腐木板；油漆未干 → 保留警示带与告示，严禁解封；
  座椅被搬动 → 核对原点位、复位重锚；已拆除待重装 → 登记暂存物料、按原基础重装。
- **并发认领**：`UPDATE … WHERE status='open'` 原子认领，多名班组同时抢单仅一组成功，
  其余收到“已被班组 X 认领”。
- **封控记录**：先设置警示带（tape_on）才能完工；撤除（tape_off）留痕。
- **复验权限**：仅巡查员可复验，且**维修人不能复验自己的工单**；驳回则退回维修，座椅继续封控。
- **未干油漆阻断**：`paint_wet=1` 时复验直接拦截；恢复使用前还必须满足
  **警示带已撤除 + 上传重开核对照片 + 现场核对勾选**，三者齐备方可恢复，事件自动结案。
- **材料消耗**：班组登记材料名称、数量、单位，随工单留存。

## 页面说明

- **地图页**：SVG 公园/街道地图，座椅标注按材质显示简洁图标（木/钢/石/塑木），
  绿色=可使用、橙色=封控/报修并有脉冲圈，蓝色水滴为模拟定位；点击标注或列表项进入详情。
- **移动端优先**：座椅与工单详情最先展示**位置与安全状态横幅**。
- **双向跳转**：地图标注/座椅列表的工单号 ↔ 工单详情里的“地图定位”，事件页同样互通。
- **维修前后照片并排**展示；复验时单独上传重开核对照片。
- 配色：公园白底、深绿主色、维修橙警示色。

## 测试

```bash
PYTHONPATH=. python3 tests/test_workflow.py -v
```

12 个用例，覆盖题目要求的四项：

1. **并发认领**（服务层 8 线程 + HTTP 层 6 线程，各仅 1 个赢家）
2. **错误归并**（跨座椅拒绝、并入已结事件拒绝、结案后再报损开新事件、重复报损自动合并）
3. **复验权限**（非巡查员拒绝、施工本人自验拒绝、他人通过）
4. **未干油漆阻断**（油漆未干 → 警示带未撤 → 缺照片 → 未勾选核对，逐级拦截，齐备后恢复）

## 目录结构

```
run.py                 # 启动入口（初始化数据 + HTTP 服务）
app/
  db.py                # SQLite 连接、建表（WAL、外键）
  services.py          # 领域规则：归并/认领/封控/完工/复验/照片/材料
  location.py          # 定位模拟适配器（可替换为真实 GPS）
  server.py            # ThreadingHTTPServer + JSON API
  seed.py              # 演示数据
  web/                 # 单页前端（index.html / app.js / styles.css）
tests/test_workflow.py # 业务规则 + HTTP 端到端测试
data/                  # seats.db 与 photos/（运行后生成，已忽略）
```

## 常用接口

| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/seats` `/api/seats/{id}` | 全部 | 台账/详情（含未结事件） |
| POST | `/api/reports` | 市民 | 报损，自动归并或开工单 |
| GET | `/api/work-orders` `/api/work-orders/{id}` | 全部 | 工单列表/详情（报损、封控、照片、材料、复验） |
| POST | `/api/work-orders/{id}/claim` | 班组 | 原子认领 |
| POST | `/api/work-orders/{id}/closures` | 班组 | `tape_on` / `tape_off` |
| POST | `/api/work-orders/{id}/finish` | 班组 | 完工（可带 `paint_wet`） |
| POST | `/api/work-orders/{id}/paint-dry` | 施工班组 | 解除未干油漆标记 |
| POST | `/api/work-orders/{id}/inspect` | 巡查员 | 通过/驳回，校验阻断项 |
| POST | `/api/work-orders/{id}/materials` | 班组 | 材料消耗 |
| POST | `/api/seats/{id}/photos` | 分角色 | 报损/维修前/维修后/重开照片 |
